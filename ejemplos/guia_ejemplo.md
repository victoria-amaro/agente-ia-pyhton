# Guía de estudio: Listas de Python

## Explicación

Una lista conserva varios valores en un orden definido.

```python
nombres = ["Ana", "Luis"]
print(nombres[0])
```

## Práctica

Escribe una función que devuelva la cantidad de nombres de una lista.
